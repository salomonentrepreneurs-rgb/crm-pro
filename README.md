# CRM Pro

A professional AI-powered CRM platform with lead management, deal pipeline, AI scoring, team collaboration, and analytics dashboards

## ✨ Features

- **Full-Stack Architecture**: React 19 + FastAPI + PostgreSQL
- **Authentication**: JWT + OAuth2 ready
- **Responsive Design**: Works on desktop, tablet, and mobile
- **Docker Support**: One-command deployment
- **CI/CD**: GitHub Actions pipeline

## 🤖 CRM Module

- AI-powered lead scoring
- Deal pipeline management
- Activity tracking
- Smart analytics dashboard
- Auto follow-up scheduling

## 🚀 Quick Start

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Docker
```bash
docker-compose up
```
